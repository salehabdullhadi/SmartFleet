# SmartFleet - نظام إدارة الأسطول الذكي

## نظرة عامة
SmartFleet هو نظام متكامل لإدارة الأسطول يتضمن:

## مكونات المشروع

### 📱 SmartFleet.Web
تطبيق الويب الرئيسي المطور بـ ASP.NET Core
- لوحة التحكم الرئيسية
- إدارة المركبات والسائقين
- تتبع الرحلات والمواقع
- إدارة المستخدمين والأذونات

### 📱 SmartFleet.Mobile  
تطبيق الجوال المطور بـ Flutter
- تطبيق للسائقين
- تتبع المواقع في الوقت الفعلي
- إشعارات فورية

### ⚡ SmartFleet.Arduino
كود الأجهزة المدمجة (IoT)
- أجهزة تتبع المركبات
- حساسات المحرك والوقود
- إرسال البيانات للخادم

### 📚 Documentation
- مخططات قاعدة البيانات
- دليل الإعداد والتركيب
- وثائق API

### 🧪 SmartFleet.Tests
- اختبارات الوحدة
- اختبارات التكامل

## متطلبات التشغيل
- .NET 8.0 أو أحدث
- SQL Server
- Flutter SDK (للتطبيق المحمول)
- Arduino IDE (للأجهزة المدمجة)
