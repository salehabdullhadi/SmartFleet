# 📦 SmartFleet.Shared

## نظرة عامة
هذا المجلد مخصص للكود المشترك بين مكونات النظام المختلفة.

## المحتويات المخططة

### 📄 Models/
- **DTOs** - Data Transfer Objects
- **Enums** - التعدادات المشتركة
- **Constants** - الثوابت المشتركة

### 🔧 Utils/
- **Helpers** - وظائف مساعدة
- **Extensions** - إضافات للكلاسات
- **Validators** - التحقق من البيانات

### 🌐 API/
- **Contracts** - واجهات API
- **Responses** - نماذج الاستجابة
- **Requests** - نماذج الطلبات

## الاستخدام
```csharp
// مثال على الاستخدام
using SmartFleet.Shared.Models;
using SmartFleet.Shared.Enums;
```
